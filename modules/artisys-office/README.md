# ArtiSys Office

Fronteira comum para conteúdo Office sem servidor obrigatório.

- descritor portátil de DOCX/XLSX/PPTX;
- adapter para `docxjs/renderAsync`;
- conversão de matrizes de dados para snapshot básico de workbook Univer;
- request portátil para execução local sob demanda do PPT Master.

Armazenamento, permissões, templates empresariais e componentes de UI ficam no consumidor.
