# artisys-documents

Base de inteligência de documentos usando OpenCV para pré-processamento e PaddleOCR para OCR.

**Consumir como:** `snapshot`, porque classificação, campos obrigatórios e regras de assinatura variam por produto.

Fluxo esperado: `scanner/arquivo -> preprocessamento -> OCR -> normalização -> classificação do consumidor -> destino final`.
