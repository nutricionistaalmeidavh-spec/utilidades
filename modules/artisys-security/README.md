# artisys-security

Pipeline comum de segurança para os repositórios ArtiSys.

Integra Gitleaks, Trivy e Semgrep como ferramentas de desenvolvimento/CI, mantendo as fronteiras de licença registradas no catálogo.

**Consumir como:** `shared`.

**Meta:** todos os produtos ativos devem conseguir adotar o mesmo conjunto mínimo de checks sem duplicar configuração.
