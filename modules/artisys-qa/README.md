# artisys-qa

Kit compartilhado de QA baseado em Playwright.

**Objetivo:** padronizar login, navegação, screenshots Chromium, smoke tests e fluxos críticos em aplicações web e Electron que exponham UI testável.

**Consumir como:** `shared`.

**Não colocar aqui:** regras de negócio específicas do PDV, obra, clínica ou outro produto. Cada consumidor mantém seus cenários específicos e reutiliza o harness comum.
