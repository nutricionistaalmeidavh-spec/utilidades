# ArtiSys Licensing

Kit ArtiSys reutilizável. Estado: **implemented 0.1.0**.

**Contrato:** Offline-verifiable license contract using Ed25519 public-key signatures; private signing key stays outside client applications.

## Verificação

```bash
npm test
npm run check
npm run example
npm pack --dry-run
```

Nenhum serviço pago ou infraestrutura permanente é obrigatório.
