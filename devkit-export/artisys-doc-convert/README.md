# ArtiSys Document Convert

Kit ArtiSys reutilizável. Estado: **implemented 0.1.0**.

**Contrato:** Portable document-conversion contract over an isolated on-demand Gotenberg adapter.

## Verificação

```bash
npm test
npm run check
npm run example
npm pack --dry-run
```

Nenhum serviço pago ou infraestrutura permanente é obrigatório.
