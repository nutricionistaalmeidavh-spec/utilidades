# ArtiSys UI Builder

Schema de página/blocos reutilizável com adapters para três editores aprovados.

- árvore de blocos com IDs únicos;
- projeto inicial para GrapesJS;
- `Data` portátil para Puck;
- árvore de elementos para binding em Craft.js.

O módulo não define o design system do produto. Cada consumidor registra componentes, CSS, assets, persistência e publicação.
