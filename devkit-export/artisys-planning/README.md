# ArtiSys Planning

Contrato comum de cronograma para projetos ArtiSys.

- valida tarefas, datas e dependências;
- gera tarefas Frappe Gantt;
- gera eventos FullCalendar;
- calcula progresso médio;
- detecta sobreposição de tarefas para o mesmo recurso/equipe.

Não é solver nem scheduler em background: regras de negócio e persistência ficam no consumidor.
