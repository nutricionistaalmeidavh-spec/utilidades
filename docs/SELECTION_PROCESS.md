# Processo de selecao

1. Buscar candidatos no GitHub.
2. Eliminar bibliotecas genericas que nao adicionam capacidade de produto diferenciada.
3. Eliminar repositorios que exigem infraestrutura always-on.
4. Verificar licenca e se o core funciona sem servico pago obrigatorio.
5. Identificar ao menos um uso concreto em produto ArtiSys.
6. So entao apresentar o candidato ao usuario.
7. Apenas candidatos aprovados pelo usuario sao pinados no catalogo canonico e adicionados como submodules.
